# 合成演示数据

日期基准 `2026-10-01`，2 个虚构商品（随行杯、收纳盒），每个 4 张程序绘制的参考示意图。2 个账号为 `demo_admin` 和 `demo_other`，演示密码均为 `LocalDemo-2026!`。两商品都属于前者；阶段四已实际验证另一用户不可读商品、批次、成图与事件。

数据库只初始化 draft 商品、ready 参考素材与账号，不预填识图确认、提示词确认、成功批次、成图或用量。另有 5 张磁盘 Mock 预览样例，不代表应用已经生成成功。

UUID 由固定命名空间与商品/素材标识确定。素材生成完全固定输入、无随机元数据，SHA-256 可复现。密码首次随机盐哈希，重复初始化保留；删库重建时排除哈希后比较规范化数据摘要。

来源与用途见 `demo/ASSET_SOURCES.md` 和 `demo/fixtures/assets-manifest.json`。首次初始化创建固定商品和素材；有识图记录后保留工作流，避免重启重置进度。完整闭环和实际队列已于阶段四验证。

阶段四运行后数据库中会有真实执行工作流产生的 Mock 识图、策划、任务与图片。不能用这些运行记录反推真实模型质量；初始夹具的零批次预期仍只描述空库初始化。
