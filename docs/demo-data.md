# 合成演示数据

日期基准 `2026-10-01`，2 个虚构商品（随行杯、收纳盒），每个 4 张程序绘制的参考示意图。2 个账号为 `demo_admin` 和 `demo_other`，演示密码均为 `LocalDemo-2026!`。两商品都属于前者，用于后续验证所有权边界。

数据库只初始化 draft 商品、ready 参考素材与账号，不预填识图确认、提示词确认、成功批次、成图或用量。另有 5 张磁盘 Mock 预览样例，不代表应用已经生成成功。

UUID 由固定命名空间与商品/素材标识确定。素材生成完全固定输入、无随机元数据，SHA-256 可复现。密码首次随机盐哈希，重复初始化保留；删库重建时排除哈希后比较规范化数据摘要。

来源与用途见 `demo/ASSET_SOURCES.md` 和 `demo/fixtures/assets-manifest.json`。初始化器会重写固定演示商品和素材状态；请在演示运行前初始化，完整工作流验收属于阶段四。
