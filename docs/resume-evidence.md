## 可直接选用的展示版表述

- 将商品素材、风险字段人工确认、视觉策划和初始批量生图拆分为可检查阶段，以后端确认与最小版本关联阻止旧方案提交。
- 以 Redis/Dramatiq 驱动逐图任务，结合请求幂等、数据库条件领取、租约/代次校验、SSE 与轮询实现状态恢复和仅失败项重试。
- 用 4+1 故障场景验证 [1,1,2,1,1] 尝试次数与四张结果 ID 保持；阶段五 42+21+7 项自动测试及 3 组浏览器用例通过。
