# 实际录屏分镜

视频时长 **80.72 秒**，1440×1000、25 fps、H.264 MP4、无音轨。浏览器真实操作，未加速、未拼接或伪造任务状态；转码做兼容压缩和移除输入元数据。仅裁去开头 8.5 秒的页面加载白屏，所有业务操作和等待保留原速。画面底部是录制时添加的讲解层，未修改业务源码。

| 场景计时 | 画面与操作 | 讲解字幕 |
|---|---|---|
| 0.0–5.2 秒 | 商品多模态工作流 · 实际操作录屏 | 合成参考图 / Mock 模型 / Redis + Dramatiq；程序占位图不代表真实生图质量 |
| 5.2–13.4 秒 | 01 / 四张多角度参考图 | 主参考图与素材顺序进入后端；商品和图片均为程序合成素材 |
| 13.4–25.5 秒 | 02 / 风险字段必须人工确认 | 未知材质保留为未知；后端也会拒绝绕过确认，置信度只是 Mock 固定值 |
| 25.5–39.2 秒 | 03 / 确认五张图片的策划 | 本批次关联已确认识图版本；Schema 校验数量、方向与模块布局 |
| 39.2–49.5 秒 | 04 / 实际队列执行得到 4 成功 + 1 失败 | 第 3 张首次失败由 Mock 显式注入；其他四项结果保持可用 |
| 49.5–60.1 秒 | 05 / 刷新后从数据库恢复 | 100% 代表本轮终结；成功数、失败数与重试状态分别显示 |
| 60.1–70.2 秒 | 06 / 只重试失败项，不整批重做 | 尝试次数 [1,1,2,1,1]；其余四张结果 ID 不变，记录可复核 |
| 70.2–79.0 秒 | 从参考素材，到人工确认，再到可恢复结果 | 本片只证明工作流与状态机制；不将 Mock 成图当作真实模型效果 |

计时从首个页面载入后开始；视频包含很短的页面载入间隔。`assets/demo.srt` 是同一分镜文本的计时参考；画面已包含实际讲解字幕，不要求播放器加载侧字幕。无配音，可作为面试口头讲解底片。

使用独立 Compose 项目、新合成数据卷、Mock 和独立 Worker 录制。只捕获网页，不含浏览器账号、终端、桌面或原业务素材。第 3 张故障／模型缺证据与未知引用均为明确标注的 Mock 场景，不是对真实模型的错误统计。
