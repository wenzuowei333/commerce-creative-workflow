## 本阶段新增或修改

| 模块 | 展示适配与目的 |
|---|---|
| config / Compose / Dockerfile | 独立 PostgreSQL、Redis、媒体卷与端口；默认实际 Dramatiq/Redis session；Node 构建 React 后由 FastAPI 同源提供。应用非 root，不隐式读环境文件。基础镜像固定为本次成功构建的内容摘要，避免标签漂移和重复解析。 |
| demo_provider | 从原 Mock 派生，新增未知材质的高风险字段和说明；第 3 张首次抛出明确的手动重试错误，仅在 demo+mock 下生效。不直接改任务状态。 |
| analysis API | 服务端拒绝未确认、删除或降级原高风险字段；引用必须属于当前商品 ready 素材；旧识图版本不能覆盖最新版本。保留未知值可人工确认，不强行编造材质。 |
| plan_validation / prompts | 为保留的字典 Provider 契约增加 Schema、数量、索引、模块检查。策划关联最新已确认识图，重新识图后不能创建基于旧方案的新批次。 |
| models / 两个新迁移 | 仍为 18 表；批次增加 demo_scenario、plan_version、plan_snapshot_json，策划增加 analysis_version_id 外键。原初始迁移保持不变。 |
| generation API | 短事务全局锁串行化幂等检查、批次/手动重试创建；同幂等键不同场景冲突。批次快照冻结尺寸/质量等设置。取消会失效正在执行的租约。 |
| generation_execution | 保留按 state 条件领取、attempts、引用读取、图像验证、媒体落盘与 UsageLedger；重写执行外层，在无 Provider 事务锁时调用，回写前按状态/token/attempts/有效租约重新锁定。不再让旧成功或旧失败结果清空新租约或覆盖新图片。 |
| heartbeat / recovery | 心跳增加“尚未过期”条件；恢复查询在同一短锁下行锁定并重排。新独立恢复进程周期检查过期项与已提交 queued 项，抵御提交后发消息失败。 |
| quota | UTC 日；创建时计入待执行项，领取时在锁内核对并计实际尝试。故障接管是另一次尝试。不是外部账单预授权或对账实现。 |
| workers/tasks | 保留原可重试错误的自动重试上限；新增手动失败场景设置 retryable=false，避免被后台自动重试掩盖。失去租约的执行不能再修改自动重试状态。 |
| SSE / React | SSE 支持 Last-Event-ID 的已知事件游标，断线保留浏览器原生重连并辅以轮询；页面从持久化历史恢复。商品/方案切换重新挂载结果状态，退出清空账号查询缓存。新增场景选择、成功/失败数、尝试次数与结果 ID。 |
| seed / tests / lock | 有识图记录时保留工作流；修正原测试对默认配置的假设。新增 PostgreSQL、Redis、真实独立进程与浏览器验收。重建跨平台 npm 锁以修复缺少可选依赖，直接依赖版本保持锁定；后端显式锁 greenlet 以兼容 Linux。 |

`workflow_lock` 是本展示版新增的 PostgreSQL advisory 事务锁，统一短事务顺序，牺牲吞吐换取可检查的一致性。SQLite 源测试中不模拟该锁，因此真实并发结论只来自 PostgreSQL checks。

## 不扩大的来源主张

新分析版本关联、批次设置快照、Schema 验证、恢复外层和回写隔离是本次展示改造，不能写为原生产版本已完整具备。没有实现通用依赖哈希图，也没有将素材/商品/模型的任意变化都纳入完整失效链。批次仍按执行时的商品素材读取参考；源素材变更不等于已实现严格历史快照复现。

Mock 固定档案与置信度不是识图准确率。Mock 图片为程序占位图，没有真实模型调用或收费；不代表真实多模态理解/生图效果。Actor 的消息可重复投递，租约约束本地结果写回，不保证外部接口严格一次执行。

多项目统一干净检出、CI、许可证/权属最终复核与公开发布属于后续阶段。
