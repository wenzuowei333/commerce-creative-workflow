# 演示场景

默认端口 18140，密码 `LocalDemo-2026!`。参考图为程序合成素材，Mock 输出是带标识的占位图。

| 场景 | 输入与操作 | 预期业务结果 |
|---|---|---|
| 风险确认 | demo_admin → 随行杯 → 识别商品信息；先观察未勾选状态，再人工确认未知材质 | 按钮起初不可用；服务端也拒绝删除/降级风险字段，允许保留未知 |
| 五图策划 | 选择 5 张，生成并确认提示词 | 一个视觉方向、五个子项；绑定最新已确认识图版本 |
| 部分失败 | 选择“第 3 张首次失败，手动重试”，开始生成 | 4 completed、1 failed；本轮进度 100% 不等于全成功；attempts 为 [1,1,1,1,1] |
| 刷新恢复 | 部分失败时刷新浏览器 | 同一批次与图片从数据库恢复，失败状态保留 |
| 仅重试失败项 | 点击仅补生成失败图片 | 最终 5 成功；attempts=[1,1,2,1,1]，其他四张图片 ID 不变 |
| 下载 | 选择第一张结果，下载所选 | ZIP 含选中图片及 manifest，SHA-256 可验证 |
| 正常第二商品 | 收纳盒，识图/策划确认后选择全部正常 | 五张都完成，attempts 均为 1 |
| 所有权隔离 | 退出后登录 demo_other | 商品列表为空，管理员批次、图片、参考素材、事件不可读 |
| 重新识图 | 已确认方案后重新识图，再尝试提交旧方案 | API 拒绝旧方案，要求重新策划并确认 |

主视频展示第一至六项。正常第二商品、跨账号隔离和真实进程故障由阶段五自动测试与浏览器记录覆盖，不将视频没有展示的情节说成已在视频出现。

若已有批次，可在素材步骤重新识图、确认并建立新方案后再次演示。不要直接更新数据库来伪造演示状态。后续上游素材变化尚没有完整依赖失效图，见 [版本范围](version-scope.md)。
